# Schedules

One-time schedules are for "run this workflow at X".

## Create a Schedule

Use `Endurant.schedule/3`, `Endurant.schedule/4`, or `Endurant.schedule/5`.

```elixir
scheduled_at = DateTime.add(DateTime.utc_now(), 300, :second)

{:ok, scheduled} =
  Endurant.schedule(
    MyApp.Workflows.OrderReminderWorkflow,
    %{"order_id" => "o-123"},
    scheduled_at
  )
```

To target a named instance:

```elixir
{:ok, scheduled} =
  Endurant.schedule(
    :my_endurant,
    MyApp.Workflows.OrderReminderWorkflow,
    %{"order_id" => "o-123"},
    scheduled_at
  )
```

Options:

- `:id` explicit schedule id (UUID string). If omitted, Endurant generates one.

## List Scheduled Rows

Use `Endurant.scheduled/0`, `Endurant.scheduled/1`, `Endurant.scheduled/2`.

```elixir
all = Endurant.scheduled()
pending = Endurant.scheduled(status: :pending, limit: 50)
cron_rows = Endurant.scheduled(cron_schedule_id: "c3e0-...")
instance_rows = Endurant.scheduled(:my_endurant, status: :dispatched)
```

Filters:

- `:status` one of `:pending | :dispatched | :skipped | :failed | :cancelled`
- `:cron_schedule_id` only rows generated by a specific cron schedule
- `:limit` positive integer (default `100`)

## Cancel a Scheduled Row

Use `Endurant.cancel_scheduled/1` or `Endurant.cancel_scheduled/2`.

```elixir
:ok = Endurant.cancel_scheduled(scheduled.id)
```

Cancellation is only valid for `:pending` rows.

Returns:

- `:ok`
- `{:error, :not_found}`
- `{:error, :not_pending}`

## Row Shape

`Endurant.scheduled/..` returns maps with:

- `id`
- `cron_schedule_id` (`nil` for manual one-time schedules)
- `unique_id` (derived from workflow `unique_id`)
- `queue`
- `workflow`
- `version`
- `input`
- `scheduled_at`
- `overlap_policy` (`:skip`)
- `status`
- `dispatched_execution_id` (`nil` until dispatched)
